# Update documentation
1. Identify changed behavior and any mismatches between docs and actual implementation.
2. Update only relevant files: product, architecture, roadmap, runbook or ADR.
3. For ADRs record context, decision, considered alternatives, consequences and revisit trigger.
4. Separate current implemented status from future design.
5. Verify commands and links against files that really exist.
6. Summarize changed documents and outstanding unknowns.
